Files changed (SEC-01, owner Ben)

FileWhat changed
database/migrations/002_login_throttle.sql (new)New table gym_v1.login_throttle storing the failed-attempt count, counting-window start and locked_until for each normalised email, including emails with no account, so lockouts survive a server restart.
server/src/utils/loginThrottle.js (new)Lockout logic: getActiveLock (is this email locked?), recordFailure (atomic counter, locks after 5 failures in 15 minutes), clearFailures (reset on successful login).
server/src/middleware/rateLimit.js (new)Per-IP rate limiter (10 requests/minute per endpoint) using express-rate-limit; returns HTTP 429 with Retry-After and writes an audit-log entry.
server/src/routes/auth.jsLogin now checks the lock first, always runs one bcrypt comparison (dummy hash for unknown emails), counts failures, locks the account and resets the counter on success. Rate limiter added to login, register and forgot-password.
server/src/index.js'trust proxy' changed from 'loopback' to a config setting that is off by default, so a client cannot fake its IP with an X-Forwarded-For header to avoid the rate limit.
server/src/config.jsNew settings with defaults: LOGIN_MAX_ATTEMPTS=5, LOGIN_WINDOW_MINUTES=15, LOGIN_LOCKOUT_MINUTES=15, AUTH_RATE_LIMIT_PER_MINUTE=10, TRUST_PROXY=off.
.env.exampleDocuments the optional SEC-01 settings (commented out).
server/package.json, server/package-lock.jsonAdded dependency express-rate-limit 8.7.5 (MIT).
